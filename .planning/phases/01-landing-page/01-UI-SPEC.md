## Spacing Scale

Declared values (must be multiples of 4):

| Token | rem | px | Usage |
|-------|-----|-----|-------|
| xs | 0.25rem | 4px | Icon gaps, inline padding |
| sm | 0.5rem | 8px | Compact element spacing, form field gaps |
| md | 1rem | 16px | Default element spacing, card padding |
| lg | 1.5rem | 24px | Section padding, nav item gaps |
| xl | 2rem | 32px | Layout gaps between sections |
| 2xl | 3rem | 48px | Major section breaks, hero padding |
| 3xl | 4rem | 64px | Page-level spacing, footer padding |

Exceptions: none

Tailwind v4 equivalent: `p-1` (4px), `p-2` (8px), `p-4` (16px), `p-6` (24px), `p-8` (32px), `p-12` (48px), `p-16` (64px).

## Typography

| Role | Size | Weight | Line Height | Tailwind |
|------|------|--------|-------------|----------|
| Body | 16px | 400 (Regular) | 1.5 | `text-base` |
| Label / Small | 14px | 400 (Regular) | 1.4 | `text-sm` |
| Heading (H2) | 28px | 600 (Semibold) | 1.2 | `text-2xl font-semibold` |
| Display (H1) | 48px | 600 (Semibold) | 1.1 | `text-5xl font-semibold` |
| CTA Button | 16px | 600 (Semibold) | 1 | `text-base font-semibold` |
| Nav Link | 15px | 500 (Medium) | 1 | `text-[15px] font-medium` |

Weight loading: Google Fonts imports weights 400, 500, 600, 700 per `display=swap`.

Line height defaults: Heading/Display use tighter 1.1–1.2. Body uses 1.5 for readability.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` White | Page backgrounds, card surfaces, modal backgrounds, text on dark |
| Secondary (30%) | `#1F2937` Dark Gray | Sticky nav background, footer background, alternating section backgrounds, body text |
| Accent (10%) | `#2563EB` Blue | Primary CTAs, secondary CTA hover, active nav link, form submit button, YouTube play overlay icon, key highlight text, link underlines |
| Success | `#22C55E` Green | Form success confirmation toast/banner, checkmark icons, status indicators, brand accent highlights |

**Tailwind v4 tokens:** `--color-white`, `--color-dark-gray`, `--color-blue`, `--color-green` — defined in `@theme` directive in `landing-page/src/index.css`.

Accent reserved for: Primary CTA buttons (`#2563EB`), secondary CTA hover state, navigation link hover/active state, form submit button, YouTube play button overlay, key emphasis text in hero/vision sections, anchor link hover underlines.

## Interaction Contracts

| Interaction | Behavior |
|-------------|----------|
| Sticky nav scroll | Transparent at top; solid `#1F2937` background after 80px scroll |
| Nav link click | Smooth scroll to section `id` |
| CTA button click | Open CTA modal with backdrop overlay |
| Modal backdrop click | Close modal |
| Modal close button | Close modal |
| YouTube thumbnail click | Replace thumbnail + play overlay with loaded iframe player |
| Form submit (success) | Show success state in modal, auto-close after 3s |
| Form submit (error) | Show inline error message; keep modal open |
| Section scroll reveal | Fade-in + translate-up animation on enter viewport (IntersectionObserver) |
| Hub & Spoke animation | SVG lines animate on scroll into view |
